# Troubleshoot customer creation

Use this topic if you cannot create a customer record.

## The Create customer button is not available

### Cause

Your user account may not have permission to create customers.

### Resolution

Contact your Orbit CRM administrator and request the **Create customers** permission.

!!! note
You can still view existing customer records if you have read-only access.

## A customer with this name already exists

### Cause

Orbit CRM has found a customer record with a matching or similar name.

### Resolution

1. Search for the customer.
2. Open the existing record.
3. Check whether it represents the same organisation.
4. Update the existing record instead of creating a duplicate.

!!! warning
    Do not create a second record simply to bypass the duplicate warning.

## The email address is rejected

### Cause

The email address may be incomplete or incorrectly formatted.

### Resolution

Check that the email address:

- Contains an `@` symbol
- Contains a valid domain
- Does not contain spaces

For example:

`name@example.com`

## Changes are not saved

Try the following:

1. Check your internet connection.
2. Refresh the page.
3. Enter the customer details again.
4. Select **Create**.

!!! caution
    Refreshing the page may remove information that has not yet been saved.

If the problem continues, contact your system administrator.
