# Getting started

Welcome to the demo product.

This section explains the basic steps you need to complete before you start using the system.

## Before you begin

Make sure you have:

- An active user account
- The correct access permissions
- Your organisation details

## Sign in

1. Open the application.
2. Enter your email address.
3. Enter your password.
4. Select **Sign in**.

After signing in, the dashboard opens.
