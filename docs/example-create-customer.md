# Example - Create a customer

This example shows how an account manager might create a new customer.

## Scenario

Northstar Engineering has agreed to begin a trial of Orbit CRM.

The account manager needs to create a customer record before onboarding can begin.

The customer details are:

- Customer name: Northstar Engineering
- Primary email: contact@northstar.example
- Account owner: Jamie Taylor
- Status: Prospect

## Example

1. Select **Customers**.
2. Select **Create customer**.
3. In **Customer name**, enter `Northstar Engineering`.
4. In **Primary email**, enter `contact@northstar.example`.
5. In **Account owner**, select **Jamie Taylor**.
6. In **Status**, select **Prospect**.
7. Select **Create**.

The Northstar Engineering customer record opens.

!!! tip
    Examples are useful when a task contains several fields or business decisions that may not be obvious from the procedure alone.

## Result

The account manager can now continue with the onboarding process.
